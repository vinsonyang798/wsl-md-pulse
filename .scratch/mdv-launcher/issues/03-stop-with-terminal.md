# 03: 关闭终端标签页后预览随之停止

**What to build:** 用户关闭运行 `mdv` 的终端标签页后，从这个标签页启动的所有预览在几秒内停止，不留后台进程。终端还开着时，预览一直可用；用户在这个终端里继续跑别的命令，也不影响预览。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 在 tmux 会话里为两个目录各运行一次 `mdv`，然后关闭会话：5 秒内两个 Vantage 进程和它们的看护进程都已退出
- [ ] 会话保持打开、空闲 30 秒以上，预览仍然可用
- [ ] 在同一个会话里运行并结束其他前台命令（例如运行完就退出的子 shell），预览不受影响
- [ ] 关闭会话后，`mdv list` 不再列出这些预览
