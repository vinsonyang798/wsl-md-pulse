# 07: 报错、`/mnt` 警告与帮助

**What to build:** 用户输错或环境异常时，能得到清楚的反馈：

- 目录不存在或不是目录时报错，退出码为 1；
- Vantage 启动失败（或 15 秒内没有打印地址）时，结束它的进程，把 Vantage 自己的输出转给用户，并清除记录，这样下次运行时不会误认为预览已在运行；
- 目录位于 `/mnt/` 下时只警告、照常启动；
- `mdv --help` 显示用法和安装方法。

运行状态目录只有当前用户可读写。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `mdv /不存在的路径`、`mdv <某个文件>`：stderr 输出以 `mdv:` 开头的信息，退出码为 1
- [ ] 用一个输出任意内容后立即退出的假 Vantage 启动：stderr 包含它的输出，退出码为 1，`mdv list` 不列出这个目录，也没有残留进程
- [ ] 用一个长时间不打印地址的假 Vantage 启动：约 15 秒后按启动失败处理，没有残留进程
- [ ] 在 `/mnt/` 下的目录运行：stderr 有"在 Windows 盘上、可能不刷新"的警告，预览照常可用（测试环境里没有 `/mnt` 写权限时可以跳过）
- [ ] `mdv --help` 的输出包含所有子命令和安装方法，退出码为 0
- [ ] 运行状态目录的权限是 700
