# 02: 同一目录复用，多个目录自动错开端口

**What to build:** 用户在同一个目录里再次运行 `mdv`，只会重新打开浏览器，不会启动第二个实例，打印的 URL 与第一次相同。在另一个目录运行 `mdv`，会自动得到下一个空闲端口。两个预览页同时可用，互不影响。用户环境里即使设置了 `PORT` 变量，也不影响自动选端口。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 同一目录连续运行两次：Vantage 进程只有一个，两次打印的 URL 相同，假 `cmd.exe` 被调用两次
- [ ] 同一目录的不同写法（相对路径、带 `..`、经符号链接）视为同一个预览
- [ ] 第二个目录得到 8001（8000 已被第一个占用时），两个 URL 分别只提供各自目录的内容
- [ ] 在 `PORT=9999` 的环境里运行，仍然从 8000 起自动选端口
- [ ] 实例已被外部杀掉后再运行 `mdv`，失效的记录被清掉并重新启动，不报错
