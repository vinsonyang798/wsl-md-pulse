# 08: 用户在自己的 WSL 上验收

**What to build:** 用户在自己的机器上（Win10 22H2 + WSL NAT 模式）按 spec 的用法实际用一遍，确认浏览器真的会被打开，预览页也会随 codex 的写入刷新。云端没有 Windows，这一步只能由用户本人完成。

**Blocked by:** 01, 02, 03, 05, 06

**Status:** ready-for-human

- [ ] 运行 `mdv install-vantage` 成功（如果已有探测脚本下载的二进制，也可以跳过这一步）
- [ ] 在一个项目目录里运行 `mdv`：Windows 默认浏览器自动打开预览页，能看到目录树，Mermaid 正常显示
- [ ] 让 codex 修改一篇文档：预览页在 1 秒左右内刷新，不跳回顶部
- [ ] 在第二个项目目录里运行 `mdv`：打开第二个预览页，端口不同，两个预览页同时可用
- [ ] 关闭运行 `mdv` 的终端标签页后，再打开 `mdv list`，这些预览都已不在
